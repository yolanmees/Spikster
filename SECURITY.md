## Reporting a Vulnerability

We take the security of Spikster seriously. If you discover a security vulnerability, please **do not** open a public issue.

Instead, report it privately via email to **spikster@spikster.com**, or use GitHub's [private vulnerability reporting](https://github.com/yolanmees/Spikster/security/advisories) if enabled for this repository.

You should receive an acknowledgment within 48 hours. We will investigate and release a fix as soon as possible, typically within 7 days for critical issues.

### What to include

- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Any potential impact or exploit scenario
- Your contact information for follow-up

## Bounty & Recognition

There is currently **no monetary bounty program** for Spikster. Security researchers who report valid, previously unknown vulnerabilities through the channels above are publicly recognized:

- Named acknowledgment in the [GitHub Security Advisories](https://github.com/yolanmees/Spikster/security/advisories) for their report
- Acknowledgment in release notes for the fix
- Listed in the Hall of Fame below

### Hall of Fame

- **leanworld7-netizen** — unauthenticated API routes + command injection in package install (issues #25/#26, fixed in 07722cc)

## Disclosure Process

1. Report received and acknowledged
2. Investigation and validation
3. Fix developed and tested
4. Patch released and disclosed via [GitHub Security Advisories](https://github.com/yolanmees/Spikster/security/advisories)
5. Public disclosure after the patch is available (typically 14 days after release)

We appreciate responsible disclosure and will acknowledge security researchers in our release notes.
